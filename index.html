使用指南

iPhone

是否需要联网或 API？

不需要调用 API，也不需要把账单上传到服务器。这个版本是本地自用工具：识别、分类、抵消确认和报表都在本机完成，数据保存在浏览器本地存储中。

PWA 主屏幕安装

  1. 把整个 pwa 文件夹上传到一个 HTTPS 静态网页地址，或者用你自己的局域网服务器打开。
  2. 用 iPhone Safari 访问该地址，点击分享按钮。
  3. 选择“添加到主屏幕”，保存后就会出现一个“智能账本”图标。
  4. 从主屏幕打开后，会以接近 App 的方式运行，并支持离线打开已缓存的页面。

注意：直接用 file:// 打开 HTML 时，PWA 离线缓存和添加到主屏幕能力会受限；建议用 HTTPS 地址访问。

最简单的离线用法

  1. 把 smart-ledger.html 发到你的 iPhone，比如用 iCloud Drive、隔空投送、微信文件或邮箱。
  2. 在 iPhone 的“文件”App 里找到这个 HTML 文件并打开。
  3. 如果系统提示选择打开方式，选择 Safari 或浏览器打开。
  4. 按平时流程导入账单、修改分类、确认抵消即可。

更像 App 的用法

  1. 如果你想要主屏幕图标，最稳的方式是把这个文件放到一个私人网页地址或局域网地址。
  2. 用 Safari 打开该地址后，点击分享按钮，选择“添加到主屏幕”。
  3. 之后就可以像打开 App 一样从主屏幕进入。

数据在哪里？

数据保存在当前浏览器的本地存储里。如果更换浏览器、清除网站数据或换手机，可能会丢失记录。建议每月导出一次备份文件。

备份与迁移

导出的备份是 JSON 文件，可以保存到 iCloud Drive 或发到自己的电脑。换手机、换浏览器或重新打开文件后，用“导入备份”恢复即可。

能做成安装包吗？

iPhone 不支持像 Android APK 那样直接安装任意文件。要做成 IPA 安装包，需要 Mac、Xcode 和 Apple 签名；自用安装通常需要使用开发者签名或侧载工具。更轻量的方式是做成 Safari 主屏幕 Web App。

Excel 表格导入

当前离线版已支持直接导入 .xlsx、CSV、TXT、Excel 另存为的 HTML/网页表格。.xlsx 解析使用已打包到本地的 SheetJS，处理过程在本机完成，不需要联网，也不会上传账单数据。

推荐的月度使用流程

  1. 月底打开微信、支付宝、银行账单。
  2. 能导出 CSV / 文本就导入文件；不能导出就用 iPhone 实况文本从截图复制文字。
  3. 在“导入”里粘贴或导入，再到“记录”里校对分类。
  4. 在“抵消”里确认退款、红包退回等是否抵消。
  5. 回到“统计”，选择月度、年度或自定义时间段查看报表。
